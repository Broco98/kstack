# Triage Labels

스킬들은 다섯 가지 표준 triage 역할로 말한다. 이 파일은 그 역할을 이 저장소 이슈 트래커에서 실제로 쓰는 라벨 문자열에 매핑한다.

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 메인테이너가 이 이슈를 평가해야 한다     |
| `needs-info`               | `needs-info`         | 제보자의 추가 정보를 기다리는 중         |
| `ready-for-agent`          | `ready-for-agent`    | 충분히 구체화되어 AFK 에이전트가 바로 맡을 수 있다 |
| `ready-for-human`          | `ready-for-human`    | 사람이 구현해야 한다                     |
| `wontfix`                  | `wontfix`            | 처리하지 않는다                          |

스킬이 역할을 언급하면(예: "AFK-ready triage 라벨을 적용한다") 이 표에서 대응하는 라벨 문자열을 쓴다.

"Label in our tracker" 열은 실제로 쓰는 어휘에 맞게 고친다.
